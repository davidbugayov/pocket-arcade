## Локальные файлы

- `real-war-4.6.27-arm64-v8a.xapk` — оригинальный архив, около 243 МБ.
- `com.devdop.realwar.apk` — базовый APK.
- `config.arm64_v8a.apk` — обязательный пакет нативных библиотек ARM64.

APK и XAPK сохранены в этой папке локально и исключены из Git. Это стороннее приложение-референс; исходники Pocket Arcade находятся отдельно. Передача одного Git-репозитория не передаёт эти бинарные файлы: их нужно скопировать отдельно или повторно скачать по адресу из `source.json`.

## Проверка

SHA-1 архива совпал с опубликованным для ARM64-варианта. Проверены CRC архива и обоих APK. Подписи обоих APK проверены Android SDK `apksigner`; сертификат совпадает с указанным источником. Результат — в `signature-verification.txt`, SHA-256 файлов — в `SHA256SUMS`.

Это проверка целостности и подписи, а не независимая проверка безопасности или подтверждение сертификата разработчиком. Приложение не устанавливалось и не запускалось.

## Установка на Android для изучения

Нужны оба APK и устройство/эмулятор с поддержкой ARM64. Из этой папки:

```sh
adb install-multiple com.devdop.realwar.apk config.arm64_v8a.apk
```

Базовый APK отдельно не является полным установочным комплектом. XAPK — ZIP-контейнер, а не одиночный APK. Установку выполнять отдельно, когда потребуется изучение приложения.
